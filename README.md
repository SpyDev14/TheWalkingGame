# The Walking Game
Это игра-бродилка с псевдо-трёхмерной графикой как в DOOM или (что ближе) в Wolfinstein 3D.

Иммитация 3D реализована через raycasting (с позиции игрока бросаются лучи, чем дистанция меньше - тем стена на экране больше).
